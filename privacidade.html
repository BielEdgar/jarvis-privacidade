Política de Privacidade do Jarvis

Última atualização: 24 de outubro de 2026.

O Jarvis é um assistente pessoal de uso exclusivo do seu dono, que roda no computador dele. Não é oferecido ao público.

Quais dados são acessados

  • Google Agenda: eventos, para avisar sobre compromissos.
  • Gmail: e-mails, para resumir e avisar sobre mensagens importantes; e, somente quando o dono pede e confirma, enviar respostas ou mover e-mails para a lixeira.

Como os dados são usados e guardados

  • Os dados ficam no computador do dono. O Jarvis não mantém servidor próprio nem banco de dados na internet.
  • Os dados não são vendidos, compartilhados nem usados para publicidade.
  • Trechos podem ser enviados a serviços de inteligência artificial apenas para gerar a resposta pedida pelo dono, sem armazenamento pelo Jarvis fora do computador.
  • O uso dos dados das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como remover o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
